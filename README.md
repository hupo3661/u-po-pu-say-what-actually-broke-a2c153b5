One line of software error copy that tells the user the brutal truth about what went wrong — and makes them laugh. 148 characters, one line, no wasted words.

> Something went wrong — and for once, the truth: our database fell over and took your unsaved changes with it. They are gone; retrying will not help.

The joke is the twist on the error message everyone hates: instead of hiding behind "Something went wrong", this one actually says what broke (the database fell over), what it cost (your unsaved changes), and what to do next (don't bother retrying — they're gone).

## Run it

```sh
python3 main.py
```

Prints the line to stdout and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
